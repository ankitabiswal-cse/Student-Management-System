
# Student Management System

## Project Overview
A Java Console-Based Student Management System
that helps manage student information.

## Features
- Add Student
- View All Students
- Search Student
- Update Student
- Delete Student
- Calculate Percentage
- Save and Load Student Records

## Technologies Used
- Java
- Object-Oriented Programming
- ArrayList
- File Handling
- VS Code

## How to Run

1. Install Java JDK.
2. Open the project in VS Code.
3. Open the terminal.
4. Compile the Java files:

   javac -d out src/Student.java src/StudentManagementSystem.java

5. Run the project:

   java -cp out StudentManagementSystem

## Data Storage
Student records are stored in data/students.txt.
